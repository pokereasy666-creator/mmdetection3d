## 0. 背景与要回答的问题

前面的诊断确定了三件事：

1. 提升空间在**初始 query 的定位精度**上，集中在初始位置偏差超过 0.5 m 的 17.2% 目标。只修这部分 oracle 就有 +1.725 pp，扣除覆盖收益后 L = +1.425 pp。
2. 单层解码器大约能修正一格（0.6 m）以内的偏差，偏 1–2 m 的目标几乎修不回 0.5 m 内（B0）。
3. 位置和分数是耦合的：把 query 换到另一个格子会丢掉原峰值的分数，大目标在宽阈值上会掉 AP（#2a）。所以方法应当**保留原峰值 query 及其分数，只把位置调准**。

文献查重的结论：没有找到在 BEV 融合检测里处理初始 query 定位误差的工作。人体姿态估计里处理热图量化误差的方法（DARK、UDP、Keypt2Subpx）是合适的迁移来源，并且与本仓库直接对应：训练目标的高斯画在取整后的格子上（审计 A8），初始 query 位置固定在格子中心（审计 A3）。

本文档回答四个问题：

| 编号 | 问题 | 步骤 | 是否需要训练 |
| --- | --- | --- | --- |
| P0 | 现有 heatmap 在峰值附近是否已经带有格内位置信息？ | 第 0a / 0b 步 | 否 |
| P1 | 只是多加几层解码器，能拿到多少定位收益？（最直接的竞争解释） | 第 1 步 | 是 |
| P2 | 方法 M-b（峰值偏移初始化）能拿到多少？ | 第 2 步 | 是 |
| P3 | 方法 M-a（UDP/DARK 式无偏编码 + 连续解码）能拿到多少？ | 第 2 步 | 是 |

## 5. 第 0a / 0b 步：现有 heatmap 是否带有格内位置信息（不训练）

### 5.1 第 0a 步：离线分析（必做）

用起点权重在 val 全量上推理一次（单卡，约 30 分钟），导出每个初始 query 所在峰值的 3×3 邻域 heatmap（对应类别通道的 sigmoid 值）。对每个初始 query 计算三种位置：

- **格子中心**：现有做法；
- **DARK 解码**：对邻域取 log 后，用中心差分算梯度和含交叉项的 Hessian，偏移 = −H⁻¹∇，每个方向截断到 ±0.5 格；Hessian 不是负定（含不可逆和鞍点）或峰值在边界格时退回格子中心，按原因分别计数；
- **3×3 soft-argmax**：以 sigmoid 值为权重求邻域加权中心。

对每个 GT 取最近的同类初始 query（K = 200，2 m 内），按 G0 / G1 / G2 和 <30 / ≥30 m 分组输出：

| 量 | 定义 |
| --- | --- |
| d_cell、d_dark、d_soft | 三种位置到 GT 的距离，给均值和中位数 |
| 初始召回 @0.5 m | 三种位置分别计算的 class-aware 召回率 |
| 移近比例 | d_dark < d_cell 的比例 |
| 退回计数 | DARK 退回格子中心的个数 |

### 5.2 第 0b 步：测试时探针（有条件）

只有在第 0a 步中，DARK 解码使全体初始召回 @0.5 m 提升 ≥ 0.5 pp 时才运行：在测试时把初始 `query_pos` 换成 DARK 解码位置（query 特征仍取峰值格），做一次 val 全量评测，输出相对 E0 的 ΔmAP 和各阈值贡献。

第 0a、0b 两步都只用于解释，不决定 M-a、M-b 是否开跑。

## 7. 第 2 步：方法（2 次微调）

两种方法共用一套"连续 query 位置"的实现：初始 query 的位置不再限定为格子中心，query 特征用双线性插值在连续位置上从共享 BEV 特征中采样。**top-K 的选择、峰值的类别和 `query_heatmap_score` 都保持不变**，因此覆盖不变，变的只有位置。

方法的基座取决于第 1 步的 Q5 判定（第 9 节）：基座为 1 层或 3 层解码器。

### 7.1 M-b：峰值偏移初始化（迁移自 Keypt2Subpx 的偏移学习，回归范围扩大到 ±3 格）

| 项 | 设定 |
| --- | --- |
| 偏移头 | 输入为 heatmap 头所用的同一共享 BEV 特征。结构：两层 3×3 卷积（128 通道，BN，ReLU），再接 1×1 卷积输出 2 通道；最后一层权重和偏置全部零初始化；输出经 tanh 后乘以 R = 3（单位：格） |
| 初始位置 | 选出的峰值格中心 + 该格的偏移 δ；δ 在用作 query 位置和采样位置之前 **detach**，检测损失不回传到偏移头 |
| 数值精度 | 偏移头在 fp32 下计算（与 heatmap 头相同，关闭 autocast） |
| 训练监督 | 稠密 L1：每个 GT 所在格的 Chebyshev 半径 3 格以内的格子，目标为（GT 的连续格坐标 − 该格中心坐标），每个方向截断到 ±3；一个格子同时落在多个 GT 范围内时，归给中心最近的那个 GT；每格损失为 x、y 两个方向绝对误差之和，再除以监督格数，权重 λ_off = 0.25；使用全部训练 GT，不做类别评测距离截断 |
| 其他 | 解码器的 center 仍相对 query_pos 回归；其余损失不变 |

零初始化保证训练开始时 M-b 与基座完全等价（S-M0 验证的就是这一点）。

### 7.2 M-a：无偏编码 + 连续解码（迁移自 UDP / DARK）

| 项 | 设定 |
| --- | --- |
| 训练目标 | 高斯中心改用 GT 的连续格坐标；GT 所在格的值仍设为 1（保持 focal loss 的正样本定义），半径内其他格的值按到连续中心的距离计算高斯值；高斯半径的计算方式与原实现相同 |
| 初始位置 | 训练和推理都用第 0a 步的 DARK 解码（与 0a 共用同一函数；截断 ±0.5 格，退回规则相同） |
| 参数 | 不新增参数 |

### 7.3 不在本文档范围内

M-a 与 M-b 的组合、偏移范围 R 或权重 λ_off 的调整、更多种子、全程重训，都放到后续文档，视本文档结果再定。

## 9. 预先登记的判读规则（待确认）

**定义**：
- C0 均值 = 两个 C0 种子 mAP 的平均；σ_ft = |mAP(C0-s0) − mAP(C0-s1)|。
- 稳健门槛 τ = max(0.3, 2 × σ_ft) pp。
- 捕获率 = 增益 ÷ L（L = 1.425 pp），只作描述。
- 临界标注：距阈值 ≤ 0.1 pp 时标注"临界"，结论仍按规则。

| 规则 | 判据 | 结论 |
| --- | --- | --- |
| Q5 竞争基线 | Δ_D3 = mAP(D3) − C0 均值 ≥ τ | 加层有稳健收益：第 2 步的基座改为 3 层，方法必须在 D3 之上再证明增益 |
| | Δ_D3 < τ | 加层没有稳健收益：第 2 步基座为 1 层；论文中以 D3 作为对比行 |
| Q6 方法（M-a、M-b 分别判） | Δ_M = mAP(M) − 基座 mAP ≥ max(0.5, τ) | 方法有效，进入全程训练与完整实验 |
| | τ ≤ Δ_M < max(0.5, τ) | 勉强，审阅讨论 |
| | Δ_M < τ | 无效 |
| Q7 机制核对（只对 Q6 判为有效或勉强的方法） | Δ_M 中来自 0.5 m 与 1 m 阈值的贡献 ≥ 60%，并且 mATE 下降、G1 + G2 的初始位置进入 0.5 m 的比例上升 | 不满足：增益不是来自定位，审阅讨论后才能继续 |

基座 mAP：Q5 判 1 层时为 C0 均值；判 3 层时为 D3。

**判读顺序**：自检全部通过 → Q5 → 对 M-a、M-b 分别判 Q6 → Q7。两者都有效时，下一份文档做组合；两者都无效时，C 方向在这一设计层面关闭，回到审阅。

## 12. 已知局限

- **微调不等于全程训练**：所有结论只说明"从这个权重出发、冻结 backbone、微调 N 个 epoch"条件下的差异。若方法有效，还需要全程训练确认。
- **只有两个种子**：σ_ft 是非常粗的噪声估计，τ 的下限 0.3 pp 用来防止它被低估。
- **D3 只代表一种加层方式**（复制初始化，3 层）。FocalFormer3D 中更强的 6 层 deformable 解码器不在本文档范围内。
- **起点权重比原论文 val 结果低约 2 pp**：在更强的 baseline 上，定位余量可能更小。
- **pedestrian 和 traffic_cone 的余量此前没有测出来**（这两类不做 NMS，oracle 只是多加了一个重复框）。方法对这两类的效果没有事先依据。
